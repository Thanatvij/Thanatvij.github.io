# Thanat Vijitrakanlikit — Professional Portfolio

Multi-page static portfolio for GitHub Pages. The site uses semantic HTML, responsive CSS and progressive JavaScript without a build step or external framework.

## Pages

- `/` — focused professional introduction and selected work
- `/projects/` — competition portfolio with four national competition projects
- `/personal-projects/` — personal builds with an embedded playable Tarot web app
- `/projects/bloodscope/` — flagship case study with project video and official certificates
- `/projects/pakd/` — funded NSC 2025 case study
- `/about/` — background, experience and skills
- `/contact/` — direct contact links and downloadable resume

The Google Analytics property and Google site-verification file from the existing portfolio are preserved. All internal assets use repository-relative paths and work on GitHub Pages.
